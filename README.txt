WEBSITE PORTOFOLIO STEVEN
========================

File utama:
- index.html : halaman website
- style.css  : desain, tata letak, dan responsive layout
- script.js  : menu mobile, filter karya, dan lightbox gambar
- assets/img : gambar portofolio yang diekstrak dari file MHTML sumber

CARA MEMBUKA
1. Ekstrak ZIP ke satu folder.
2. Jangan memindahkan index.html terpisah dari style.css, script.js, atau folder assets.
3. Buka index.html menggunakan Chrome, Edge, atau Firefox.

EDIT KONTAK / ISI
- Konten teks, judul proyek, dan tautan kontak bisa diedit di index.html.
- Warna, ukuran, dan tata letak bisa diubah di style.css.
- Interaksi website bisa diubah di script.js.
- Gambar ada di assets/img. Nama file gambar bisa diganti, tetapi jalurnya di index.html juga harus disesuaikan.

CATATAN
Website ini dibuat ulang berdasarkan teks dan gambar yang tersedia di MHTML yang diberikan.
Aset logo Sekolah Asoka turut disimpan sebagai aset sumber dan dipakai sebagai favicon.
Seluruh tampilan dirancang responsif untuk desktop, tablet, dan ponsel.
